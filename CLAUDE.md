# Inspetor Jirafalis · repositório público do produto

- Produto autoral de Sidney de Araujo Silva. Repositório público de portfólio: documento de apresentação,
  protótipo navegável e prints. Publicado no GitHub Pages a partir da raiz.
- `index.html`: documento de apresentação completo. `prototipo/`: telas HTML independentes (sem build).
  `prints/`: capturas usadas no README e no documento.
- **Só dados fictícios.** Pessoas, times, cards e regras são inventados. O catálogo de regras (R01, R02…) é
  ilustrativo, com regras comuns de Scrum e Kanban; códigos novos seguem a ordem de aparição na mesa.
- Nada de empresa, cliente, nome real, URL de ambiente real ou token entra aqui. Domínios de exemplo usam
  `exemplo.dev`.
- Mudou uma tela que aparece num print? Refaça o print no mesmo tamanho.
- `inscricao/` fica fora do git.
